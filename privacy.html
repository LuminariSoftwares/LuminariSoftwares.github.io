Privacy Policy

Effective October 22, 2026. Applies to the Luminari Studio app that signs in with Google.

Who uses the app

The app is private software used only by the studio owner, Timothy Murphy, with the owner's own Google accounts. It is not offered to the public.

What Google data the app uses

  • Gmail: reads the owner's own incoming messages so they can be sorted into the studio's customer inbox, and creates reply drafts in the owner's Gmail. The app never sends email; the owner reviews and sends every message personally.
  • YouTube: reads view, like and comment counts for the owner's own channel's videos.

Where the data goes

Data from Google is stored only on computers the owner owns and controls. It is not sold, rented, shared with third parties, or used for advertising. Email content is processed only by software and AI models running on the owner's own computers, not by outside AI services.

Google API Services User Data Policy

Luminari Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Stored data can be deleted on request.
